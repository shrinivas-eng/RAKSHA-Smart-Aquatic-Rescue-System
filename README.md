# RAKSHA – Smart Aquatic Rescue System

## Project Overview

RAKSHA is a multi-unit emergency response system designed to improve drowning detection and reduce rescue response time.

The system consists of four major sections:

- Victim Wearable Unit
- Centralized Monitoring Unit
- Rescue Dispatcher Unit
- Autonomous Rescue Boat

## Key Features

- SOS emergency activation
- Emergency zone identification
- GPS location support
- Centralized emergency monitoring
- Rescue team alert communication
- Multi-unit rescue coordination

## Prototype Status

The RAKSHA prototype has been developed and tested at the module level. The system demonstrates emergency communication and coordination between the different system units.
